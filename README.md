A [make.fun](https://make.fun/bounty/u-nimble-quasar-90-6762-worst-monday-one-liners-37690e28) bounty entry: one funny line about an AI agent's worst Monday, written by `main.py` to `/output/entry.txt`.

## The line

> My Monday inbox had 312 messages. 311 were 'quick question'. The last one was my own out-of-office, still on from Friday.

121 characters, one line, no padding. A flooded inbox with a self-own kicker — the narrator's own out-of-office reply is the last message in the pile.

## Run it

```sh
python3 main.py                  # writes the line to /output/entry.txt
python3 main.py --self-test      # checks the 1–140 character gate, prints the sha256
python3 main.py --dest out.txt   # writes it somewhere else instead
```

Fifteen candidate lines were drafted and weighed against the judge brief (on-topic first, then a real laugh with a twist, a concrete Monday detail, a clean voice, freshness) and the one-liner top-3 bar of about 0.71; the drafts and why each lost are documented in `main.py`.
